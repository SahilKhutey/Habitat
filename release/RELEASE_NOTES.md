# Habitat — Build the life you want to live.
## Release v1.0.0 (Release Candidate)

## Overview
**Habitat** is the definitive habit execution and discipline operating system across Android, iPhone (iOS), Web, and Backend services.

## Core Principles
1. **Action > Aspiration:** Habit reminders trigger physical action verified through camera proof.
2. **Encouragement > Punishment:** 5-minute non-lethal escalation ensures follow-through without coercive shame.
3. **Local-First & Privacy-Centric:** All core alarms, tasks, proofs, and XP function 100% offline without mandatory cloud dependencies.
