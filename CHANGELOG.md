# Changelog

All notable changes to the Habitat / Discipline Platform will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-27
### Added
- Phase 1: Engineering repository foundation & monorepo topology.
- Docker Compose development infrastructure (PostgreSQL 16, Redis 7, MinIO S3).
- Pure Dart domain engine and shared packages (`domain`, `api_contracts`, `design_system`, `shared_config`).
- NestJS / Express modular backend with `/api/v1/health` and multi-module routing.
- Flutter mobile & web clients with responsive Foundation & Command Center UI.
- Multi-layer automated testing matrix (Unit, Integration, E2E Vertical Slice).
