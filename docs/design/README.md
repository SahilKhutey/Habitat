# Design System & UX Foundation (`docs/design`)

## Visual Language
- **Background**: Deep Obsidian `#0A0A0C`
- **Surface**: Tactical Gunmetal `#141418` / `#1C1C22`
- **Wake-up Siren & Escalation**: Crimson Alert `#FF3B30`
- **Streak & Active State**: Amber Focus `#FF9500`
- **Mission Verified & XP**: Emerald Victory `#34C759`

## UX Principles
1. High contrast and immediate legibility in groggy morning states.
2. Direct action over cognitive friction: The physical shutter button is prominent and immediate.
3. Motivating, energetic, and disciplined—not punitive.
