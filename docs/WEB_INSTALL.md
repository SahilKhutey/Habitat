# Habitat Web PWA Installation & Offline Dashboard Guide

## Progressive Web App (PWA) Setup
1. Open the production URL in Chrome, Safari, Edge, or Firefox.
2. Click **Install Habitat** or **Add to Home Screen**.
3. Allow service workers to complete local asset caching.

## Offline Operation
1. Turn **OFF** your internet connection.
2. Launch Habitat from your home screen / desktop shortcut.
3. Access local task management, history, and feedback export powered by IndexedDB.
