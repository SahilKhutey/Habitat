# AI Discipline Coach & Conversational Capabilities

## 1. Core Coach Capabilities

* **Plan My Day**: Analyzes active tasks, routines, and wellness targets into a balanced daily itinerary.
* **Explain Missed Tasks**: Provides non-punitive friction diagnostics and recovery paths.
* **Simplify Routine**: Identifies overloaded schedules and proposes streamlining to 3 core habit anchors.
* **Review Progress**: Synthesizes 7-day completion rates, streaks, and strongest focus windows.

---

## 2. Structured Action Cards in Chat

When the coach proposes an optimization (e.g. *Move Evening Reflection: 22:00 $\to$ 21:30*), it renders an interactive action card with:
* `[Accept Change]`: Executes the command deterministically.
* `[Keep Current]`: Retains existing configuration without recurring pressure.
