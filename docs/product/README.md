# Product Vision & Principles (`docs/product`)

## Core Philosophy
Discipline is not merely waking up early; it is the instantaneous conversion of intent into verified physical action with zero cognitive friction.

## The Core Product Loop
$$\text{Task} \longrightarrow \text{Alarm} \longrightarrow \text{Mission} \longrightarrow \text{Proof} \longrightarrow \text{Verification} \longrightarrow \text{Reward (XP \& Streaks)}$$
